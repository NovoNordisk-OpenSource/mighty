## Commands

- Run R from the console with `--quiet --vanilla`
- Format: `air format` after generating or editing R code, but only
  format modified files, do not format the entire directory/pkg
- Test all: `devtools::test()`
- Test one file: `devtools::test_file("tests/testthat/test-filename.R")`
- Never use `devtools::test_active_file()` — it doesn’t work in this
  setup
- Full check: `devtools::check()`
- Docs: `devtools::document()` after any roxygen2 change, then
  [`pkgdown::check_pkgdown()`](https://pkgdown.r-lib.org/reference/check_pkgdown.html)
  to confirm every topic is in the reference index
- Load for interactive dev: `devtools::load_all()`

## Conventions

- Tests for `R/{name}.R` go in `tests/testthat/test-{name}.R`; fixtures
  in `tests/testthat/fixtures/`; snapshots in `tests/testthat/_snaps/`.
- Line width 120 (`.lintr`); no
  `object_usage_linter`/`object_name_linter`/`object_length_linter`/`return_linter`.
- Don’t edit `man/` — generated by roxygen2.
- Sentence case for all headings, in docs and roxygen.
- For PRs, check that the version number in DESCRIPTION has been bumped
- Project uses MegaLinter cspell. Keep `inst/WORDLIST` sorted with
  `LC_ALL=en_US.UTF-8 sort -o inst/WORDLIST inst/WORDLIST` after adding
  entries
